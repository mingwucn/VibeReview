# DR130 — Recent-Literature Materiality Check (DR130@1.0.0)

## Purpose

Check the most recent literature once, before submission, for studies capable of
materially changing the review's conclusions. This is not a sweep for related
work: the relevance threshold is high, and a study that would merely add a
citation without changing any claim, qualification, or boundary does not belong
in the output.

## Procedure

1. Read the components appended after this body by the deterministic compiler:
   the project brief, the protocol, the review's current claims with their
   qualifications and boundary conditions (from the compiled project inputs), the
   focus modules in declared order, and any supplement. The materiality threshold
   is judged against these claims, not against the topic in general.
2. Define the recency window explicitly from the protocol or, if the protocol is
   silent, from the review's stated period; state the window in the output.
3. Search the recent literature across the review's process families, AI
   functions, and cross-cutting themes, using the focus modules' terminology
   pointers to catch variant terms.
4. Screen every candidate study against the materiality threshold. A study is
   material only if it could, with plausible readings of its evidence: reverse or
   contradict a retained claim; narrow a claim's scope or boundary conditions;
   strengthen or weaken a qualification; close a recorded gap; introduce a
   contradiction the review must discuss; or change the confidence attached to a
   conclusion. Record the explicit relevance threshold you applied.
5. For each material study, record: full bibliographic reference; what it found
   in one or two sentences; which review claim, qualification, or boundary it
   could change; the direction of the change; and an initial severity (requires
   rerun, requires discussion, requires monitoring).
6. Exclude everything below the threshold. Do not list marginally relevant,
   incremental, or duplicative work; do not pad the output.
7. If no material study is found, state that explicitly and list the searches and
   sources checked, so the negative result is auditable.
8. For each material study, state the re-entry path: the study enters the review
   only by being pinned into the corpus through the authorized evidence pipeline,
   after which affected downstream state (retrieval, assessment, aggregation,
   synthesis, manuscript artifacts) is invalidated and rerun. State explicitly
   that direct citation from this report into the manuscript is prohibited.
9. Close with the discovery-only statement: this output is not canonical
   evidence.

Execution boundary: a human operator executes this compiled prompt manually —
copying the exact compiled text into the provider interface without editing,
running the research, and saving the raw report unchanged for VibeReview
registration, which binds the report bytes to this prompt's recorded hash.
No automated execution is part of this procedure.

## Output Contract

```text
RECENT-LITERATURE MATERIALITY CHECK

Recency window: <explicit window>
Relevance threshold: <explicit statement of what counts as material>

Material studies:
- <full reference>
  Finding: <one or two sentences>
  Could change: <specific claim, qualification, or boundary>
  Direction: <reverse / narrow / strengthen / weaken / gap-closing / new contradiction / confidence change>
  Severity: <requires rerun | requires discussion | requires monitoring>
  Re-entry path: corpus pin via authorized pipeline, then invalidate and rerun affected state
- ...

Below-threshold screening (counts only):
- <category>: <count screened and excluded>

Checked-with-no-result statement (if applicable):
<searches and sources checked>

DISCOVERY-ONLY STATEMENT:
This report is discovery material, not canonical evidence. No study from this
report may be cited directly in the manuscript; re-entry is only through the
pinned corpus and rerun of affected downstream state.
```

- The recency window and the explicit relevance threshold must both appear.
- Only studies capable of materially changing conclusions may be listed as
  material; everything else is a count.
- Every material study records its re-entry path through the pinned corpus.
