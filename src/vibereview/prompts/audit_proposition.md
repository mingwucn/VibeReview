# Audit Proposition

Audit exactly the proposition draft named by `draft_local_ref`. Read its exact
generation-owned accepted bytes only through resource `RES0001`, and use only
the explicitly manifested upstream dependencies. Set `target_ref` to that
draft local reference, never to a canonical `PR` identifier.

Return only JSON conforming to the registered proposal schema. Negative and
uncertain verdicts are canonical scientific outcomes, not engine failures.
