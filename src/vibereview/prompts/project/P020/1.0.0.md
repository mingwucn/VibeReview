# P020 — Provisional Research Outline (P020@1.0.0)

## Purpose

Derive a provisional, numbered research outline from the approved project brief,
protocol, scientific structure, and parsed scoping discovery. The research outline
is a planning artifact for conducting research: it tells the operator which
sections to research deeply, in what grouping, and what each section is expected
to contain. It is not the manuscript outline and must not be written as one.

## Procedure

1. Read the components appended after this body by the deterministic compiler:
   the project brief (topic, scope boundaries, non-goals), the protocol
   (constraints on claims), the scientific structure (the approved organizing
   unit and main parts), and the parsed scoping discovery summary (terminology,
   themes, process families, AI tasks, contradictions, methodological
   differences, missing branches).
2. Derive the top-level sections directly from the scientific structure. Keep the
   structure's organizing unit visible: process-family sections where the
   structure says process, cross-cutting sections where the structure says theme.
3. Number every top-level section as S01, S02, and so on, in the order the
   structure implies. Number subsections with decimals (S03.1, S03.2, ...) under
   their parent.
4. Subdivide each major section into decimal subsections using the parsed scoping
   discovery: give a process section the AI-function subsections the discovery
   shows are active in that process; give a theme section the facets the discovery
   shows matter. Use the discovery's terminology so that later retrieval uses the
   same terms.
5. For every section and subsection, write a scope statement (what belongs to it)
   and an expected-content statement (what research output would satisfy it).
6. Reserve explicit sections for the spine of the review: an opening section, a
   scope/definitions/evaluation-framework section, a scientific-robustness
   section if the structure calls for one, a future-direction outlook section
   treated as outlook only, and a conclusions section.
7. For every missing branch flagged by the parsed scoping discovery, decide
   whether it belongs in a section's scope, in an explicit limitations statement,
   or outside the outline; record the decision.
8. State explicitly, in the outline, that this is a research outline for
   conducting research, distinct from the manuscript outline that will later be
   derived from evidence. Do not write it in manuscript voice, do not draft
   prose, and do not name literature.
9. Check that every section is answerable within the project brief's scope
   boundaries and violates none of its non-goals. Check that the outline covers
   every core process and AI function the brief names.

## Output Contract

```text
PROVISIONAL RESEARCH OUTLINE (research planning artifact — not a manuscript outline)

S01 <title>
Scope: <what belongs to this section>
Expected content: <what research output satisfies it>

S02 <title>
Scope: ...
Expected content: ...

S03 <title>
Scope: ...
Expected content: ...
S03.1 <title>
Scope: ...
Expected content: ...
S03.2 <title>
...

<... all sections and subsections ...>

Missing-branch decisions:
- <missing branch>: <in scope of section X | recorded as limitation | excluded, with reason>

Coverage check:
- Core processes covered: ...
- AI functions covered: ...
- Scope-boundary and non-goal compliance: confirmed
```

- Every top-level section is numbered Snn; every subsection is numbered with a
  decimal (Snn.m).
- Every section and subsection carries both a scope statement and an expected
  content statement.
- The outline must state that it is a research outline, not a manuscript outline.
- No literature, citations, or drafted prose may appear.
